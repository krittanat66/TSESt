# ประเภทธุรกรรมงานจัดประโยชน์ทรัพย์สิน (21 ประเภท)

ใช้ตารางนี้เพื่อระบุว่าบันทึกข้อความที่กำลังร่าง/ตรวจสอบ เป็นธุรกรรมประเภทใด เพื่อกำหนด flow, เอกสารประกอบ, และระดับผู้อนุมัติที่เหมาะสม

**หมายเหตุ:** ตารางนี้ไม่ระบุตัวเลขค่าธรรมเนียม/อัตรา/เพดานวงเงินจริง — ให้ผู้ใช้กรอกเองตามระเบียบภายในปัจจุบัน

---

## กลุ่ม A: One-Stop Service — เสร็จภายในวันเดียว (9 ประเภท)

คำร้องกลุ่มนี้เป็นเรื่องมาตรฐาน ความเสี่ยงต่ำ (ด้านกายภาพ/สาธารณูปโภคของที่พักอาศัย) พิจารณาอนุมัติได้ ณ จุดบริการเดียว ไม่ต้องส่งเรื่องข้ามหน่วยงาน

| # | ประเภทคำร้อง | ลักษณะ | ผู้อนุมัติ (ระดับ) |
|---|---|---|---|
| 1 | ขออนุญาตปลูกสร้างอาคารพักอาศัย (อาคารเตี้ย/ชั่วคราว) | รวมรั้วชั่วคราว | ระดับปฏิบัติการ/หัวหน้าหน่วยพื้นที่ |
| 2 | ขออนุญาตซ่อมแซมโดยไม่เปลี่ยนสภาพอาคาร | หลังคา ฝ้าเพดาน ประตู-หน้าต่าง สี ผนัง | ระดับปฏิบัติการ/หัวหน้าหน่วยพื้นที่ |
| 3 | ขออนุญาตแก้ไข/ปรับปรุงซ่อมแซม (ไม่กระทบโครงสร้าง) | ต่อเติมเล็กน้อย ช่องระบายอากาศ โครงหลังคา | ระดับปฏิบัติการ/หัวหน้าหน่วยพื้นที่ |
| 4 | ขออนุญาตดำเนินการด้านไฟฟ้า | มิเตอร์ไฟฟ้า, EV charger, โซลาร์เซลล์ | ระดับปฏิบัติการ/หัวหน้าหน่วยพื้นที่ |
| 5 | ขออนุญาตดำเนินการด้านน้ำประปา | ติดตั้ง/ย้ายมาตรวัดน้ำ | ระดับปฏิบัติการ/หัวหน้าหน่วยพื้นที่ |
| 6 | ขออนุญาตปักเสาพาดสายไฟฟ้า | — | ระดับปฏิบัติการ/หัวหน้าหน่วยพื้นที่ |
| 7 | ขออนุญาตเปลี่ยนชื่อ-สกุลผู้เช่า | — | ระดับปฏิบัติการ/หัวหน้าหน่วยพื้นที่ |
| 8 | ขออนุญาตให้มีสัตว์เลี้ยง | — | ระดับปฏิบัติการ/หัวหน้าหน่วยพื้นที่ |
| 9 | ขอหนังสือรับรองการเป็นผู้เช่า | — | ระดับปฏิบัติการ/หัวหน้าหน่วยพื้นที่ |

**Flow มาตรฐานกลุ่ม A:**
```
ยื่นเรื่อง ณ จุดบริการผู้เช่า → เจ้าหน้าที่คัดแยกประเภท → ตรวจเอกสาร/คุณสมบัติ
→ ชำระค่าธรรมเนียม (ถ้ามี) → พิจารณาอนุมัติทันที → ออกหนังสือ/รับกลับวันเดียวกัน
```

## กลุ่ม B: ธุรกรรมเช่า/โอนสิทธิ — Flow อนุมัติหลายชั้น (12 ประเภท)

ธุรกรรมกลุ่มนี้ต้องคำนวณอัตราผลตอบแทน ตรวจสอบสิทธิ/คุณสมบัติละเอียดกว่า และอาจต้องอนุมัติหลายระดับตามมูลค่า

| # | ประเภทธุรกรรม | จุดตรวจสอบสำคัญ | เอกสารประกอบที่มักต้องใช้ |
|---|---|---|---|
| 1 | ประมูลสิทธิการเช่า | ต้องผ่าน TOR/คณะกรรมการประกวดราคา | เอกสารประกวดราคา, หลักประกันซอง |
| 2 | โอนสิทธิการเช่า (กรณีทายาท) | ลำดับทายาทสายตรง จำกัด 1 คน | หลักฐานความเป็นทายาท, ทะเบียนสมรส/บุตรบุญธรรม (ถ้าอ้างสิทธิ) |
| 3 | โอนสิทธิการเช่า (กรณีบุคคลอื่น) | ไม่ใช่ทายาท ใช้เกณฑ์/อัตราต่างจากกรณีทายาท | เอกสารแสดงตัวตนผู้รับโอน, ความยินยอมผู้เช่าเดิม |
| 4 | ขอรับเช่าแทนผู้เช่าเดิมที่ถึงแก่กรรม (ทายาท) | พิสูจน์สายตรง, ตรวจหนี้ค้างชำระก่อนอนุมัติ | ใบมรณบัตร, หลักฐานทายาท |
| 5 | เช่าตรง — ผู้เช่าร่วมเดิมขอเช่าเฉพาะส่วน | แบ่งแยกพื้นที่ตามเกณฑ์ขั้นต่ำ | ผังแบ่งแยกพื้นที่ |
| 6 | เช่าตรง — ผู้เช่าเดิมประพฤติผิดสัญญา | ต้องมีการบอกเลิกสัญญาเดิมก่อน | บันทึกการผิดสัญญา/แจ้งเตือน |
| 7 | เช่าตรง — บุคคลอื่น (ที่ดิน/อาคารว่าง) | ตรวจสภาพพื้นที่ว่าง/บุกรุก | รายงานสำรวจพื้นที่ |
| 8 | เช่าตรง — สิ่งปลูกสร้างเสียหาย/เหตุสุดวิสัย | ตรวจสอบสาเหตุความเสียหาย | รายงานความเสียหาย/ภาพถ่าย |
| 9 | การแบ่งแยก/ยุบรวมแปลง | เกณฑ์ขนาดพื้นที่ขั้นต่ำต่อแปลง | ผังแบ่งแยก/รวมแปลง |
| 10 | การถอนชื่อผู้เช่าร่วม | ความยินยอมผู้เช่าร่วมที่เหลือ | หนังสือยินยอม |
| 11 | การเปลี่ยนวัตถุประสงค์การเช่า | อัตราค่าเช่าอาจเปลี่ยนตามวัตถุประสงค์ใหม่ | คำชี้แจงวัตถุประสงค์ใหม่ |
| 12 | การนำสถานที่เช่าออกให้เช่าช่วง | ต้องขออนุญาตก่อน มีส่วนแบ่งผลประโยชน์ | สัญญาเช่าช่วงที่เสนอ |

**Flow มาตรฐานกลุ่ม B:**
```
ยื่นคำขอ → เจ้าหน้าที่จัดประโยชน์ตรวจสอบคุณสมบัติ + ลงพื้นที่สำรวจ
→ ตรวจสอบสิทธิ/หนี้ค้างชำระ → คำนวณอัตราค่าเช่า/ค่าธรรมเนียม/เงินประกันตามหลักเกณฑ์ปัจจุบัน
→ จัดทำบันทึกข้อความเสนอตามลำดับชั้น (ระดับกลาง → รองผู้อำนวยการสายงาน → ผู้อำนวยการ
   ถ้ามูลค่าสูงหรือกรณีพิเศษ) → อนุมัติ → แจ้งผล/จัดทำสัญญาใหม่
```

**ระดับผู้อนุมัติ (tiered by value — ไม่ระบุตัวเลขเพดานจริง):**
1. ระดับกลาง (ผู้อำนวยการเขตพื้นที่ / หัวหน้าสายงานจัดประโยชน์) — ธุรกรรมมาตรฐานตามหลักเกณฑ์
2. ระดับสูง (รองผู้อำนวยการฯ ตามสายงาน — อาจต้องอนุมัติร่วมหลายท่าน) — มูลค่าเกินกรอบมาตรฐาน หรือกรณีพิเศษ
3. ระดับสูงสุด (ผู้อำนวยการทรัพย์สินพระมหากษัตริย์) — นโยบาย/มูลค่าสูงมาก
4. กรณีพิเศษ: ต้องผ่านคณะกรรมการเฉพาะกิจ (เช่น คณะกรรมการประกวดราคา) ก่อนเสนอผู้มีอำนาจลงนาม

## หมายเหตุการเลือกอายุสัญญา

ธุรกรรมกลุ่ม B ส่วนใหญ่มี 2 เส้นทางคู่ขนานให้พิจารณา:
- **สัญญาระยะสั้น (ปกติ)** — ต่อสัญญาเป็นรอบ
- **สัญญาระยะยาว** — กรณีมีการลงทุนก่อสร้าง อายุยาวกว่า เมื่อครบกำหนดต้องส่งคืนสภาพเดิม เว้นแต่มีเงื่อนไขขอสิทธิต่อพิเศษ

ให้ระบุในบันทึกข้อความว่ากำลังเสนอเส้นทางใด เพราะมีผลต่อการคำนวณอัตราและเอกสารประกอบ
