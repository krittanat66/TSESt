# แบบฟอร์มตรวจสอบและรายงานผล (งานตรวจตราสัญญาเช่า)

ใช้คู่กับ `references/inspection-workflow.md` — ไฟล์นี้ให้โครงสร้างแบบฟอร์มที่ใช้จริงในแต่ละขั้นของ flow ตรวจสอบสัญญาระยะยาว

## ภาพรวม: ฟอร์ม 2 ชั้น

```
ชั้น 1: บันทึกผลตรวจสอบหน้างาน (รายผู้เช่า 1 ราย ต่อ 1 ฟอร์ม)
              │  รวบรวมผลจากผู้เช่าทุกรายในกลุ่มสัญญาเดียวกัน
              ▼
ชั้น 2: หนังสือสรุปผลระดับกลุ่มสัญญา (เสนอผู้บริหาร)
```

ห้ามข้ามชั้น 1 ไปเขียนชั้น 2 ตรง ๆ โดยไม่มีข้อมูลรายผู้เช่ารองรับ — ชั้น 2 ต้องอ้างอิงกลับไปยังฟอร์มชั้น 1 ของแต่ละรายเสมอ (ใช้ "หมายเลขอ้างอิง" เชื่อมกัน)

---

## ชั้น 1: แบบบันทึกผลตรวจสอบหน้างาน (รายผู้เช่า)

**ผู้ใช้ฟอร์ม:** เจ้าหน้าที่จัดประโยชน์ผู้ลงพื้นที่จริง (ต้องมีอย่างน้อย 2 คนร่วมลงพื้นที่)

### โครงสร้างหน้า 1 — Checklist

```
[หัวเรื่อง] แบบบันทึกผลการตรวจสอบสถานที่เช่า
เลขที่อ้างอิง: [เลขที่แปลง/สัญญา]        วันที่ตรวจ: [วันที่]

หมวดที่ 1: ข้อมูลสถานะผู้เช่า
   ☐ คงเดิม   ☐ พบการเปลี่ยนแปลง — รายละเอียด: ______________

หมวดที่ 2: ข้อมูลสภาพสิ่งปลูกสร้าง

   ☐ คงเดิม   ☐ พบการเปลี่ยนแปลง — รายละเอียด: ______________

   ☐ คงเดิม   ☐ พบการเปลี่ยนแปลง — รายละเอียด: ______________

ผู้ให้ข้อมูลสถานที่เช่า: [ชื่อ] ☐ ผู้เช่าเอง ☐ บุคคลอื่น (ระบุ) ____  เบอร์ติดต่อ: ______

ลงชื่อ ................ (ผู้ให้ข้อมูล)          วันที่ ......
ลงชื่อ ................ (เจ้าหน้าที่ผู้บันทึก)    วันที่ ......
ลงชื่อ ................ (เจ้าหน้าที่ผู้ร่วมตรวจ)  วันที่ ......

### โครงสร้างหน้า 2 — ใบแนบรายละเอียดทรัพย์สิน

พื้นที่สำหรับแนบภาพถ่ายสถานที่เช่า (ระบุวันที่ถ่ายกำกับ) พร้อมคำอธิบายลักษณะทรัพย์สินและที่ตั้งโดยย่อ

---

## ชั้น 2: หนังสือสรุปผลระดับกลุ่มสัญญา

**ผู้ใช้ฟอร์ม:** เจ้าหน้าที่จัดประโยชน์ผู้รวบรวม/สรุปผล เพื่อเสนอผู้บริหารตามลำดับชั้น — ใช้รูปแบบหนังสือราชการ (ใกล้เคียงบันทึกข้อความ ท.ก. ๖๒ แต่มีตารางสรุปผลแทนย่อหน้าเนื้อหาปกติ)

### โครงสร้างหน้า 1

```

เรื่อง  รายงานผลการตรวจสอบสถานที่เช่า [ทำเล/กลุ่มสัญญา] จำนวน [n] อัตรา

### โครงสร้างหน้า 2 — ภาคผนวก

- แผนที่สังเขปพื้นที่ที่ตรวจ
- สรุปการใช้ประโยชน์ตามสัญญาเช่า แยกประเภท (อยู่อาศัย / อยู่อาศัยและหาประโยชน์ / หาประโยชน์) พร้อมจำนวนอัตราแต่ละประเภท
- ตารางเทียบราคาประเมินที่ดิน ณ วันทำสัญญา vs ปัจจุบัน (ใช้ placeholder ตัวเลขเสมอ)
- ตารางอ้างอิง: ประเภทการเปลี่ยนแปลง ↔ หมายเลขอ้างอิง (เชื่อมกลับไปฟอร์มชั้น 1 ของแต่ละราย)

## รูปแบบ "รายงานผลตรวจภาคสนาม" (ทางเลือกกระชับกว่าหนังสือชั้น 2)

ใช้เมื่อต้องการสรุปเป็นรายงานภาพถ่ายประกอบ ไม่ใช่หนังสือราชการเต็มรูปแบบ — มี 2 variant:

**Variant A — หน่วยไม่มีการเปลี่ยนแปลง**
```
[ชื่อรายงาน] รายงานผลตรวจสอบ — ครบรอบ [n] ปี / สัญญา 15 ปี
ที่ตั้ง: [ตำบล/เขต]   กลุ่มประเภทการใช้ประโยชน์: [ระบุ]   วันที่ถ่ายภาพ: [วันที่]

[ตาราง: ภาพถ่าย 1 ภาพ | ลำดับ/แปลง | หมายเหตุ]
```

**Variant B — หน่วยมีการเปลี่ยนแปลง**
```
[หัวเรื่องเดียวกับ Variant A] + จำนวนหน่วยที่พบการเปลี่ยนแปลงทั้งหมด: [n]

[ชุดภาพถ่ายประกอบหลายมุมต่อ 1 แปลง]

┌────────┬──────────────┬──────────────────┬─────────────────────┐
│ ลำดับ   │ หมายเลขแปลง   │ การเปลี่ยนแปลง      │ การดำเนินงาน         │
├────────┼──────────────┼──────────────────┼─────────────────────┤
│ [n]    │ [รหัส]        │ [ประเภท — ดูตาราง] │ [มาตรการตอบสนอง]     │
└────────┴──────────────┴──────────────────┴─────────────────────┘
```

---

## ตารางประเภทการเปลี่ยนแปลง ↔ การดำเนินการมาตรฐาน

ใช้เติมคอลัมน์ "การเปลี่ยนแปลง" และ "การดำเนินงาน" ในฟอร์มชั้น 2 และ Variant B ด้านบน — เป็น pattern ที่พบซ้ำบ่อยที่สุด (ไม่ใช่กฎตายตัว ให้ผู้ใช้ยืนยันตามข้อเท็จจริงจริงเสมอ):

| ประเภทการเปลี่ยนแปลง | คำอธิบาย | การดำเนินการมาตรฐาน |
|---|---|---|
| **ผู้เช่าถึงแก่กรรม** | ผู้เช่าเดิม (บุคคลธรรมดา) เสียชีวิต | ทายาทยื่นเรื่องราวขอรับเช่าแทนผู้เช่าเดิม (อ้างอิง `transaction-types.md` ธุรกรรมกลุ่ม B #4) |
| **ต่อเติม/ซ่อมแซมไม่ได้รับอนุญาต** | มีการดัดแปลง/ต่อเติมสิ่งปลูกสร้างโดยไม่ยื่นขออนุญาตก่อน | สั่งระงับการดำเนินการ + ให้ผู้เช่ายื่นขออนุญาตให้ถูกต้องย้อนหลัง |
| **เปลี่ยนวัตถุประสงค์การใช้ประโยชน์** | เช่น จากที่อยู่อาศัย → เชิงพาณิชย์ โดยไม่ได้รับอนุญาต | ให้ผู้เช่ายื่นคำร้องขอเปลี่ยนวัตถุประสงค์การเช่าให้ตรงกับการใช้งานจริง (อ้างอิง `transaction-types.md` ธุรกรรมกลุ่ม B #11) |
| **เช่าช่วงไม่ได้รับอนุญาต** | นำพื้นที่ (ทั้งหมด/บางส่วน) ออกให้บุคคลอื่นใช้ประโยชน์โดยไม่ขออนุญาต | ให้ผู้เช่ายื่นขออนุญาตเช่าช่วงให้ถูกต้อง (อ้างอิง `transaction-types.md` ธุรกรรมกลุ่ม B #12) |
| **เปลี่ยนสถานะนิติบุคคล** | ผู้เช่านิติบุคคลเปลี่ยนแปลงอำนาจบริหาร/โครงสร้างผู้ถือหุ้น | ส่งเรื่องให้สำนักงานกฎหมายตรวจสอบก่อนพิจารณาต่อ |

## กฎการเขียนรายงาน/สรุป (สำคัญ)

- ใช้ **placeholder เสมอ** สำหรับจำนวนอัตรา, ราคาประเมิน, ชื่อผู้เช่า, เลขที่แปลง — ห้ามเดา/hardcode ตัวเลขจากตัวอย่างที่เคยเห็น
- ระบุ **หมายเลขอ้างอิง** เชื่อมฟอร์มชั้น 1 กับชั้น 2 เสมอ เพื่อให้ตรวจสอบย้อนกลับได้
- เอกสารชั้น 2 คือ "รายงานเพื่อทราบ" ไม่ใช่ "ขออนุมัติ" — อย่าใช้คำว่า "จึงเรียนมาเพื่อพิจารณาอนุมัติ" กับรายงานประเภทนี้ ให้ใช้ "จึงเรียนมาเพื่อโปรดทราบ" แทน (ต่างจากบันทึกขออนุมัติธุรกรรมใน `SKILL.md` หลัก)
