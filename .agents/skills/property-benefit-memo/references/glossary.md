# คำศัพท์เฉพาะทางงานจัดประโยชน์ทรัพย์สิน

ใช้ตรวจสอบว่าบันทึกข้อความใช้คำศัพท์ถูกต้อง — สับสนคำเหล่านี้เป็นสาเหตุตัวสะกด/ความหมายผิดที่พบบ่อย

| คำศัพท์ | ความหมาย/บริบทการใช้ |
|---|---|
| **การจัดประโยชน์** | งานบริหารจัดการทรัพย์สิน (ที่ดิน/อาคาร) เพื่อหารายได้/ผลตอบแทนให้สำนักงานฯ |
| **ผู้เช่า** | แบ่งเป็น 4 กลุ่ม: หน่วยงานราชการ/รัฐวิสาหกิจ, ผู้เช่าหาประโยชน์เชิงพาณิชย์, สมาคม/มูลนิธิ, ผู้เช่าอยู่อาศัย/หาประโยชน์พออยู่ชีพ |
| **สัญญาเช่าประเภทที่ 1** | สัญญาเช่า**ที่ดิน** — เช่าเฉพาะที่ดิน สิ่งปลูกสร้างเป็นกรรมสิทธิ์ของ**ผู้เช่า** |
| **สัญญาเช่าประเภทที่ 2** | สัญญาเช่า**อาคาร** — เช่าที่ดินพร้อมอาคาร สิ่งปลูกสร้างเป็นกรรมสิทธิ์ของ**สำนักงานฯ** |
| **สัญญาเช่าปกติ** | อายุสัญญาสั้น ต่อสัญญาเป็นรอบตามกำหนด |
| **สัญญาเช่าระยะยาว/สัญญาเช่าสร้าง** | มีการลงทุนก่อสร้าง อายุยาวกว่าปกติ (มีเพดานตามระเบียบ) ครบกำหนดต้องคืนสภาพเดิม เว้นแต่มีเงื่อนไขสิทธิต่อพิเศษ |
| **อัตราผลตอบแทน** | อัตราร้อยละใช้คำนวณค่าเช่าจากมูลค่าทรัพย์สิน แตกต่างตามประเภทผู้เช่า |
| **ค่าเช่าเป้าหมาย/ค่าเช่าฐาน** | ค่าเช่าที่คำนวณจากสูตรมาตรฐาน (มูลค่าที่ดิน+ต้นทุนอาคาร) ก่อนคูณด้วย % ผลตอบแทนของกลุ่มผู้เช่า |
| **ราคาประเมินที่ดิน** | ราคาจากกรมธนารักษ์ แบ่งเป็น "รายบล็อก" (กลุ่มตามแนวถนน/ซอย) และ "รายแปลง" (เฉพาะแปลง) |
| **ราคาค่าก่อสร้างอาคาร** | ราคามาตรฐานจากกรมธนารักษ์ หรือหน่วยงานประเมินอิสระ (กรณีต้องละเอียดกว่า) |
| **ทายาท (บริบทงานเช่า)** | ทายาทสายตรง: คู่สมรส, บิดามารดา, บุตร-หลานสายตรง, พี่น้องร่วมบิดามารดา หรือบุตรบุญธรรม (จดทะเบียนครบระยะเวลาที่กำหนด) — จำกัดสิทธิรับเช่าต่อได้ 1 คน |
| **เงินประกันการเช่า** | เงินมัดจำ คำนวณเป็นจำนวนเท่าของค่าเช่ารายเดือน (อัตราต่างกันตามกลุ่มผู้เช่า) |
| **เช่าช่วง** | ผู้เช่านำสถานที่เช่าไปให้บุคคลอื่นเช่าต่อ ต้องขออนุญาต สำนักงานฯ เรียกส่วนแบ่งผลประโยชน์ |
| **โอนแบ่งแยก** | แบ่งแยกสิทธิการเช่าที่ดินเป็นแปลงย่อย (มีเกณฑ์ขนาดพื้นที่ขั้นต่ำ) |
| **จำนำสิทธิ (นำสิทธิเช่าเป็นประกันหนี้)** | ใช้สิทธิการเช่าค้ำประกันสินเชื่อกับสถาบันการเงิน มีเพดานวงเงินเทียบมูลค่าโครงการ |
| **พื้นที่ใช้สอย** | พื้นที่อาคาร = กว้าง × ลึก × จำนวนชั้น ใช้เป็นฐานคำนวณค่าเช่าอาคาร |
| **พื้นที่ว่าง** | สถานที่เช่าไม่มีการใช้ประโยชน์/สิ่งปลูกสร้างถาวร หรือถูกปล่อยร้าง/มีผู้บุกรุก |
| **เช่าตรง** | การจัดให้เช่าโดยไม่ผ่านการประมูล ใช้ในกรณีเฉพาะ (ผู้เช่าเดิม/ทายาท/สภาพพื้นที่พิเศษ) |
| **TOR / คณะกรรมการประกวดราคา (BID)** | ขั้นตอนสำหรับธุรกรรมมูลค่าสูง เช่น ประมูลสิทธิเช่า ต้องผ่านคณะกรรมการเฉพาะกิจก่อนอนุมัติ |
| **ต้นสังกัด** | หน่วยงาน/ผู้บังคับบัญชาต้นทางของเรื่อง ใช้ในบริบทส่งเรื่องกลับเมื่อกระบวนการไม่สำเร็จ (เช่น คู่สัญญาไม่มาทำสัญญา) |

## คำที่มักสะกดผิดหรือใช้สับสน

| ผิดบ่อย | ที่ถูกต้อง |
|---|---|
| อสังหาริมทัพย์ | อสังหาริมทรัพย์ |
| ผลประโยชน์ / ผลตอบแทน (ใช้ปนกัน) | แยกให้ชัด: "อัตราผลตอบแทน" ใช้กับสูตรคำนวณค่าเช่า, "ผลประโยชน์" ใช้เชิงกว้าง (การจัดประโยชน์) |
| นิติกรรม | ตรวจสอบบริบท: การทำนิติกรรม เช่น การต่อสัญญา โอนสิทธิ ไม่ใช่ "นิติกรรรม" (สะกดผิดตัว ร ซ้ำ) |
| เช่าช่วง vs เช่าต่อ | "เช่าช่วง" = sublease (ผู้เช่าให้คนอื่นเช่าต่อ), "ต่อสัญญาเช่า" = renewal (ต่ออายุกับผู้ให้เช่าเดิม) — ห้ามใช้แทนกัน
