# วงจรการตรวจสอบสัญญาเช่าระยะยาว (15 ปี)

ใช้อ้างอิงเมื่อร่าง/ตรวจ/สรุปเอกสารที่เกี่ยวกับการตรวจตรา ลงพื้นที่ หรือรายงานผลระหว่างอายุสัญญา — ต่างจากธุรกรรมใน `transaction-types.md` ที่เป็นคำขอจากผู้เช่า (one-shot) เรื่องนี้คือ **กระบวนการเชิงรุกที่สำนักงานฯ ริเริ่มเอง เป็นรอบ ๆ ตลอดอายุสัญญา**

**ขอบเขต:** ครอบคลุมเฉพาะกระบวนการภายในสำนักงานฯ (ตรวจ → รายงาน → เสนอผู้บริหาร → แจ้งผู้เช่า) **ยังไม่ครอบคลุม** การส่งจดหมาย/ประสานงานกับหน่วยงานราชการภายนอก (กรมที่ดิน, เทศบาล ฯลฯ) ซึ่งเป็นคนละ flow ที่จะเพิ่มภายหลัง

## ทำไมต้องมี flow นี้แยกจากสัญญาปกติ

สัญญาปกติ (อายุสั้น ~3 ปี) มีจุดทบทวนสถานะผู้เช่า/ทรัพย์สินอยู่แล้วทุกครั้งที่ต่อสัญญา — สัญญาระยะยาว 15 ปีไม่มีจุดต่อสัญญาถี่แบบนั้น จึงต้อง **สร้างจุดตรวจสอบเทียมแทรกทุกช่วงค่าเช่า (ทุก 3 ปี)** เพื่อไม่ให้ปล่อยผ่านการเปลี่ยนแปลงสำคัญไปตลอด 15 ปีโดยไม่มีใครทบทวน

| ประเด็น | สัญญาปกติ | สัญญา 15 ปี |
|---|---|---|
| จุดทบทวนสถานะ | เกิดเองทุกครั้งที่ต่อสัญญา | ต้องสร้างจุดตรวจแทรกทุกรอบ 3 ปี |
| เอกสารหลัก | แบบขออนุมัติต่อสัญญา | แบบรายงานผลตรวจสอบ (เสนอ "เพื่อทราบ" เท่านั้น) |
| กรณีไม่ปฏิบัติตาม | ไม่ต่อสัญญาได้เลยเมื่อครบกำหนด | ต้องผ่าน escalation 3 ขั้นก่อนจะลดสิทธิ |

## Flow หลัก (วนซ้ำทุกรอบ 3 ปี จนครบ 15 ปี)

```
[1] สำนักงานทะเบียนและสัญญา
        แจ้งรายชื่อสัญญาที่ใกล้ครบกำหนดช่วงค่าเช่ารอบถัดไป (ล่วงหน้าตามกรอบเวลาที่กำหนด)
        │
[2] สำนักงานเทคโนโลยีสารสนเทศ
        จัดทำแบบสำรวจ/รายงานจากฐานข้อมูลกลาง สำหรับใช้ลงพื้นที่
        │
[3] หน่วยงานจัดประโยชน์ (ผู้ปฏิบัติหลัก)
        ลงพื้นที่ตรวจสอบจริง ต่อผู้เช่า 1 ราย ใช้ checklist 4-5 หมวด
        (ดูรายละเอียดฟอร์มใน references/inspection-forms.md)
        │
[4] ส่งต่อหน่วยงานสนับสนุนตามประเด็นที่พบ (ถ้ามี)
        ├─ พบประเด็นสถานะบุคคล/นิติบุคคล → สำนักงานกฎหมาย
        └─ พบประเด็นสภาพสิ่งปลูกสร้าง/ไฟฟ้า → สำนักงานบริหารงานก่อสร้างและรังวัด
        │
[5] หน่วยงานจัดประโยชน์
        รวบรวมผล จัดทำรายงานผลตรวจสอบ (ระดับกลุ่มสัญญา)
        │
[6] เสนอผู้มีอำนาจ "เพื่อทราบ" (ไม่ใช่ขออนุมัติต่อสัญญา — สัญญายังไม่ครบอายุ)
        │
        ├─ ไม่พบปัญหา → บันทึกประวัติ ปิดรอบ
        │
        └─ พบปัญหาต้องแก้ไข → ออกหนังสือแจ้งผู้เช่า → เข้าเส้นทาง Escalation (ดูด้านล่าง)
        │
[7] บันทึกระเบียนประวัติ (เก็บสะสมทุกรอบ — ใช้อ้างอิงย้อนหลังและชี้แจงกรณีมีข้อพิพาท/อุบัติเหตุในอนาคต)
        │
[8] วนกลับไปขั้นตอน [1] สำหรับรอบถัดไป จนครบอายุสัญญา 15 ปี
```

## เส้นทาง Escalation (เมื่อผู้เช่าไม่ปฏิบัติตามที่แจ้ง)

```
พบปัญหา (เช่น ต่อเติมไม่ขออนุญาต / เปลี่ยนวัตถุประสงค์ / เช่าช่วงไม่ได้รับอนุญาต)
   │
   ▼
[รอบ 1] ออกหนังสือแจ้งให้ปรับปรุง/แก้ไข ภายในกรอบเวลาที่กำหนด
   │  (ยังไม่แก้ไขภายในกำหนด)
   ▼
[รอบ 2] ออกหนังสือเตือนซ้ำ ภายในกรอบเวลาเดียวกันอีกครั้ง
   │  (ยังไม่แก้ไขภายในกำหนด)
   ▼
[บันทึกรับทราบ] ทำบันทึกรับทราบอย่างเป็นทางการว่าผู้เช่าไม่ดำเนินการ
   │  (ครบรอบช่วงค่าเช่า 3 ปี ยังไม่แก้ไข)
   ▼
[มาตรการ] ยุติสัญญาเช่าระยะยาว 15 ปี → เปลี่ยนเป็นทำสัญญาใหม่อายุสั้น 3 ปีแทน
          (เป็นการลดสิทธิ ไม่ใช่การยกเลิกสัญญาทันที — บีบให้ผู้เช่าต้องดูแลทรัพย์สินสม่ำเสมอ)
```

**ข้อควรระวังตอนร่างหนังสือแต่ละขั้น:** ระบุให้ชัดว่ากำลังอยู่ขั้นไหนของ escalation (เตือนรอบ 1 / รอบ 2 / บันทึกรับทราบ) เพราะน้ำเสียงและผลทางกฎหมายต่างกัน — เตือนรอบแรกยังเป็นคำขอ ส่วนบันทึกรับทราบคือการยืนยันข้อเท็จจริงเพื่อใช้ประกอบการลดสิทธิสัญญา

## หน่วยงานที่เกี่ยวข้อง (ทั้งหมดเป็นหน่วยงานภายในสำนักงานฯ)

| หน่วยงาน | บทบาทใน flow นี้ |
|---|---|
| สำนักงานทะเบียนและสัญญา | ต้นทางแจ้งเตือนสัญญาใกล้ครบรอบ |
| สำนักงานเทคโนโลยีสารสนเทศ | จัดทำรายงาน/แบบสำรวจจากฐานข้อมูลกลาง |
| หน่วยงานจัดประโยชน์ | ลงพื้นที่ตรวจจริง จัดทำรายงาน ติดตามผู้เช่า (ผู้ปฏิบัติหลัก) |
| สำนักงานบริหารงานก่อสร้างและรังวัด | ตัดสินใจเชิงเทคนิคว่าสิ่งปลูกสร้าง/ไฟฟ้าจำเป็นต้องปรับปรุงหรือไม่ |
| สำนักงานกฎหมาย | ตรวจสอบสถานะบุคคล/นิติบุคคลเมื่อพบประเด็นด้านสิทธิ |
| ผู้มีอำนาจ/หัวหน้าสำนักงาน | รับทราบ/ลงนามหนังสือแจ้งผู้เช่า |

## หมวดตรวจสอบมาตรฐาน 4 หมวด (ใช้ทุกรอบ)

1. **สถานะผู้เช่า** — บุคคลธรรมดา: ยังมีชีวิต/ถึงแก่กรรม/โอนสิทธิหรือไม่; นิติบุคคล: เปลี่ยนแปลงอำนาจบริหารหรือไม่
2. **การใช้ประโยชน์** — ยังตรงวัตถุประสงค์เดิมหรือเปลี่ยนไป (เช่น อยู่อาศัย → เชิงพาณิชย์)
3. **การเช่าช่วง** — มีการนำไปให้เช่าช่วงต่อโดยไม่ได้รับอนุญาตหรือไม่
4. **สภาพสิ่งปลูกสร้าง** — ต่อเติม/ดัดแปลงไม่ได้รับอนุญาต, สภาพทรุดโทรมเสี่ยงอันตราย/อัคคีภัยหรือไม่

**เกณฑ์ความเสี่ยงที่ต้อง flag เพื่อบังคับปรับปรุง:** ผู้เช่าไม่ดูแล/ปล่อยทิ้งร้าง, ให้บุคคลอื่นใช้ประโยชน์โดยมิชอบ, สิ่งปลูกสร้างทรุดโทรม
